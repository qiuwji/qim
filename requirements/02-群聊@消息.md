# 02-群聊@消息

## 一、需求背景

QIM 群聊中缺少 @消息功能。在多人群聊中，用户需要通过 @指定成员来引起对方注意，这是群聊的核心交互之一。

## 二、目标用户

所有 QIM 群聊参与者。

## 三、功能范围

### 3.1 发送 @消息

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| @成员 | 在群聊输入框中输入 @，弹出成员列表，选择成员后插入 @昵称 | 消息内容中包含 @标记，被 @者收到特殊通知 |
| @多人 | 一条消息可以 @多个成员 | 所有被 @者都收到通知 |
| @全部 | 输入 @全体成员 可 @群内所有人 | 仅群主/管理员可用，所有成员收到通知 |
| 纯文本 @ | @只是文本标记，不影响消息类型 | msg_type 不变，mention 信息独立携带 |

### 3.2 接收 @通知

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| @通知推送 | 被 @的成员收到推送，即使会话设置了免打扰 | 免打扰会话也推送 @通知 |
| @消息高亮 | 消息列表中被 @自己的消息有视觉标记 | 显示"有人@我"或高亮 |
| 会话列表提示 | 被 @后，会话列表显示"@我"标记 | 替代或补充未读数显示 |

### 3.3 不做的事

| 不做 | 原因 |
|------|------|
| 单聊 @ | 单聊只有两个人，@无意义 |
| @消息的撤回特殊处理 | @消息撤回和普通消息一致 |
| @消息的编辑 | 当前不支持消息编辑 |
| @历史记录查询 | 后续迭代 |

## 四、用户流程

### 4.1 发送 @消息

```
用户在群聊输入框输入 @
  → 弹出成员选择列表（支持搜索）
  → 选择成员，输入框插入 @昵称
  → 继续输入消息内容
  → 发送消息，携带 mention_uids 列表
```

### 4.2 接收 @通知

```
群聊中有人 @了我
  → 即使会话免打扰，也收到推送通知
  → 会话列表显示"@我"标记
  → 进入聊天后，@我的消息有视觉标记
```

## 五、交互规格

### 5.1 @触发

- 输入框中输入 `@` 字符时，弹出成员选择浮层
- 浮层显示群成员列表，支持搜索过滤
- 选择成员后，输入框插入 `@昵称 `（带空格）
- `@全体成员` 选项仅在当前用户是群主/管理员时显示

### 5.2 消息展示

- @文本在消息中高亮显示（蓝色链接样式）
- 被 @自己的消息在气泡上有额外标记

### 5.3 会话列表

- 被 @的会话在列表中显示"@我"文字，替代或补充未读数

## 六、业务规则

1. @消息仅在群聊中生效，单聊中输入 @不触发成员选择
2. 被 @的成员即使设置了免打扰，也必须收到推送通知
3. `@全体成员` 仅群主和管理员可用
4. mention_uids 在消息发送时确定，不可修改
5. 消息内容中的 @文本只是展示标记，mention_uids 是权威数据
6. 一条消息最多 @50 人（防止滥用）

## 七、风险

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| @全体成员被滥用 | 低 | 骚扰群成员 | 仅群主/管理员可用 |
| mention_uids 过大 | 低 | 存储和传输开销 | 限制最多50人 |

## 八、工作量

```
后端：1天
前端：2天
联调：1天
合计：4天
```
