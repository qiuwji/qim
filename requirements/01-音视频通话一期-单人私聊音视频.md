# 音视频通话一期：1对1私聊音视频

## 一、需求背景

QIM 当前仅支持文字和图片消息，缺少实时音视频沟通能力。本期在私聊会话中新增语音通话和视频通话功能，满足用户实时沟通的需求。

## 二、目标用户

所有 QIM 注册用户。

## 三、核心场景

- 用户在私聊中想和对方语音/视频沟通，不想打字
- 用户收到好友来电，需要及时知道并选择是否接听
- 用户在通话中需要基本控制（静音、挂断等）

## 四、功能范围

### 4.1 发起通话

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 语音通话入口 | 私聊会话界面提供"语音通话"按钮 | 点击后发起语音呼叫 |
| 视频通话入口 | 私聊会话界面提供"视频通话"按钮 | 点击后发起视频呼叫 |
| 被叫方不在线 | 主叫方发起呼叫时，被叫方不在线 | 主叫方立即收到"对方不在线"提示 |
| 被叫方忙线 | 主叫方发起呼叫时，被叫方正在通话中 | 主叫方立即收到"对方忙线"提示 |
| 主叫方忙线 | 主叫方自己正在通话中，再次发起呼叫 | 提示"你正在通话中" |
| 取消呼叫 | 主叫方在等待接听时取消呼叫 | 被叫方来电通知消失，主叫方回到空闲 |

### 4.2 接听/拒绝

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 来电通知 | 被叫方收到来电弹窗 + 铃声 | 显示来电人、通话类型（语音/视频） |
| 接听 | 被叫方点击接听 | 双方进入通话 |
| 拒绝 | 被叫方点击拒绝 | 主叫方收到"已拒绝"提示 |
| 呼叫超时 | 被叫方 30 秒未接听 | 双方收到"超时"提示 |

### 4.3 通话中

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 静音/取消静音 | 用户关闭/打开自己的麦克风 | 对方能感知到对方静音状态 |
| 开关摄像头 | 用户关闭/打开自己的摄像头 | 视频通话中可切换，关闭后对方看到黑屏 |
| 挂断 | 任一方点击挂断 | 通话结束，双方回到空闲 |
| 通话时长 | 显示当前通话持续时间 | 从接通开始计时，实时更新 |

### 4.4 多设备

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 多设备来电 | 用户多个设备同时收到来电通知 | 所有在线设备都弹出通知 |
| 多设备接听互斥 | 用户在一个设备接听后，其他设备来电消失 | 只有第一个接听生效，其他设备自动关闭来电弹窗 |

### 4.5 异常处理

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 网络断开 | 通话中网络断开 | 通话自动结束，提示"连接已断开" |
| 浏览器权限拒绝 | 用户拒绝麦克风/摄像头权限 | 引导用户开启权限，无法通话时给出明确提示 |
| NAT 穿透失败 | 双方网络无法直连 | 提示"网络不支持通话" |

## 五、用户流程

### 5.1 发起通话

```
主叫方点击"语音通话"或"视频通话"
  → 服务器检查被叫方状态
    → 被叫方不在线 → 主叫方看到"对方不在线"
    → 被叫方忙线   → 主叫方看到"对方忙线"
    → 被叫方空闲   → 主叫方看到"呼叫中"，被叫方收到来电通知
```

### 5.2 被叫方响应

```
被叫方收到来电通知
  → 点击接听 → 双方进入通话
  → 点击拒绝 → 主叫方看到"已拒绝"
  → 30秒未操作 → 双方看到"超时"
```

### 5.3 通话中

```
通话进行中
  → 任一方挂断 → 通话结束
  → 网络断开 → 通话自动结束
  → 静音/取消静音 → 对方感知状态变化
  → 开关摄像头 → 对方看到画面变化
```

### 5.4 主叫方取消

```
主叫方在"呼叫中"状态点击取消
  → 被叫方来电通知消失
  → 主叫方回到空闲
```

## 六、交互规格

### 6.1 通话入口

- 位置：私聊会话顶部工具栏
- 两个按钮：语音通话（麦克风图标）、视频通话（摄像头图标）
- 群聊中不显示通话按钮

### 6.2 来电通知

- 全屏/弹窗形式，显示来电人头像、昵称、通话类型
- 铃声提醒（iOS Safari 可能在接听后才能播放）
- 两个操作按钮：接听（绿色）、拒绝（红色）
- 页面不可见时弹出浏览器系统通知

### 6.3 通话界面

- 语音通话：显示双方头像 + 通话时长 + 控制栏
- 视频通话：对方画面全屏 + 本方画面小窗 + 控制栏
- 控制栏：静音、摄像头（视频通话时显示）、挂断

### 6.4 状态提示

| 状态 | 主叫方看到 | 被叫方看到 |
|------|-----------|-----------|
| 呼叫中 | "呼叫中..." + 取消按钮 | 来电通知 |
| 已接听 | 通话界面 | 通话界面 |
| 已拒绝 | "对方已拒绝" | - |
| 已取消 | - | 来电消失 |
| 超时 | "无人接听" | "已超时" |
| 忙线 | "对方忙线" | - |
| 不在线 | "对方不在线" | - |
| 已结束 | "通话结束" + 时长 | "通话结束" + 时长 |

## 七、业务规则

1. 同一用户同一时刻只能参与一通电话（忙线判断）
2. 通话仅限私聊会话，群聊不支持
3. 通话不需要好友关系，任何在线用户之间都可以通话
4. 呼叫超时时间为 30 秒
5. 通话时长从接通时刻开始计算
6. 网络断开即结束通话，不做宽限期
7. 多设备同时接听，只有第一个生效

## 八、不做的事

- 群组音视频通话
- 通话录制
- 屏幕共享
- TURN 中继（NAT 穿透失败提示用户）
- 通话记录在聊天消息中展示
- 宽限期（网络断开即结束）

## 九、风险

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| NAT 穿透失败 | 15-20% | 通话建不起来 | 提示"网络不支持"，后续加 TURN |
| iOS Safari 音频限制 | 高 | 来电铃声可能无声 | 接听按钮点击后播放 |
| 浏览器权限拒绝 | 中 | 无法获取麦克风/摄像头 | 检测权限，引导用户开启 |
